## 📌 Description
The **Augaton SCP Hacking-Device Reloaded** is a reworked and improved version of the original SCP hacking device addon.

It provides better control, persistent button blocking, and admin-friendly tools, making it ideal for SCP Roleplay servers that require secure and configurable hacking mechanics.

> ⚠️ **IMPORTANT**  
> This addon requires additional content listed on the Workshop page.  
> Without the required content, the addon will **not function correctly**.

---

## 🔧 Features
- 💻 Reloaded and improved SCP hacking device
- 🔒 Persistent button blocking (saved after restart)
- 🛠️ Admin TOOL for in-game configuration
- 📜 Superadmin-only commands
- 🎯 Designed for SCP Roleplay servers
- 🔄 Based on the original hacking device addon

---

## 🧪 Commands
> **Superadmin only**

- `hdevice_block_button`  
  Blocks a button from being hacked.  
  The block **persists even after a server restart**.

- `hdevice_unblock_button`  
  Unblocks a previously blocked button.

💡 You can also manage blocked buttons using the **TOOL**.

---

## 📥 Installation
1. Subscribe to the addon on the Steam Workshop
2. Subscribe to **all required content** listed on the Workshop page
3. Restart your server or game
4. Configure button permissions using commands or the TOOL
